estrutura html

As peças que constroem toda página web

Um guia rápido sobre tags, atributos e a diferença entre organizar conteúdo e dar significado a ele.

<tags>

Um vocabulário fixo, não uma folha em branco

O HTML trabalha com um conjunto de tags já definido e padronizado pelo W3C, não é possível inventar novas tags. Cada tag é escrita entre os sinais < e >, e quase todas precisam ser fechadas repetindo o nome com uma barra na frente.

<h1>Título de uma seção</h1> <p>Parágrafo contendo um texto</p>

Algumas tags fogem dessa regra e se fecham sozinhas, como a quebra de linha:

Linha um<br /> Linha dois

As tags se dividem em três famílias, de acordo com o papel que exercem: estruturais, textuais e semânticas. As duas últimas são o foco deste guia.

<atributos>

Atributos: detalhes dentro da tag

Um atributo acrescenta uma característica a uma tag. Ele sempre vem em pares de nome e valor, dentro da própria tag de abertura.

<img src="imagem.jpg" alt="minha imagem" />
src

Define o endereço e o nome do arquivo de imagem a ser carregado.

alt

Texto alternativo, exibido caso a imagem não carregue no navegador.

<textuais>

Tags textuais: organizam o conteúdo

Cuidam de textos, mídias e links a matéria-prima visível de uma página.

tagfunção
<h1>…<h6>Títulos hierárquicos. Use apenas um <h1> por página; os demais níveis podem se repetir.
<p>Parágrafos de texto.
<pre>Texto pré-formatado, preservando espaços e quebras de linha.
<div>Agrupa conteúdo sem carregar significado semântico próprio; quebra o fluxo em bloco.
<span>Como a <div>, mas embutida agrupa sem quebrar o fluxo do texto.
<a>Insere links.
<br>Quebra de linha.
<hr>Linha horizontal, geralmente usada para separar mudanças de assunto.
<semânticas>

Tags semânticas: dão significado à estrutura

Chegaram com o HTML5 para descrever o que cada bloco de conteúdo representa, não apenas como agrupá-lo.

<!-- uma section pode reunir vários articles --> <section> <article>Post do blog 1</article> <article>Post do blog 2</article> </section>
<section>

Define uma seção do documento, normalmente para agrupar conteúdo relacionado.

<article>

Um bloco de conteúdo independente, como um post de blog.

<formatação>

Negrito e itálico têm duas versões cada

Visualmente, <b> e <strong> parecem idênticos — assim como <i> e <em>. A diferença aparece em leitores de tela, que usam a versão semântica para dar ênfase real na leitura em voz alta.

tagefeito
<b>Aplica negrito, sem carga semântica.
<strong>Aplica negrito e marca o trecho como importante.
<i>Aplica itálico, sem carga semântica.
<em>Aplica itálico e dá ênfase ao trecho.
<listas>

Listas: três formas de agrupar itens

O HTML oferece três tipos de lista. Cada uma tem uma tag "pai" (o container) e tags "filhas" (os itens).

tipocontaineritemdescrição
Ordenada<ol><li>—
Não ordenada<ul><li>—
Definição<dl><dt><dd>
<ol> <li>Primeiro passo</li> <li>Segundo passo</li> </ol> <ul> <li>Café</li> <li>Chá</li> </ul> <dl> <dt>HTML</dt> <dd>Linguagem de marcação para estruturar páginas</dd> </dl>

O símbolo de ordenação (1, 2, 3...) e o bullet visual podem ser alterados via CSS. Também é possível aninhar listas dentro de listas.

<tabelas>

Tabelas: dados organizados em linhas e colunas

Servem para representar dados tabulares não para montar o layout da página, um uso comum antigamente que prejudica a semântica, o peso da página e a acessibilidade.

tagfunção
<table>Container principal da tabela.
<tr>Define uma linha.
<td>Define uma coluna; precisa estar dentro de uma <tr>.
<th>Coluna de título, com função semântica e estilo próprio.
<thead>Agrupa o cabeçalho da tabela.
<tfoot>Agrupa o rodapé da tabela.
<table> <thead> <tr><th>Nome</th><th>Idade</th></tr> </thead> <tr><td>Ana</td><td>28</td></tr> </table>
rowspan

Expande uma célula por várias linhas. O valor indica quantas.

colspan

Expande uma célula por várias colunas. O valor indica quantas.

<mídias>

Vídeo e áudio direto na página

Com o HTML5, incorporar mídia ficou simples, sem precisar de plugins externos.

<video src="apresentacao.mp4" controls loop></video> <audio src="trilha.mp3" controls autoplay></audio>
src

Endereço do arquivo — local ou de um site.

controls

Exibe os controles nativos do navegador (play, pausa, volume).

autoplay

Inicia a reprodução automaticamente ao carregar a página.

loop

Repete a reprodução ao chegar ao final.

A HTML5 também define media events, que permitem controlar vídeo e áudio via JavaScript.

<formulários>

Formulários: a porta de entrada da interação

É como o usuário envia dados para uma página um cadastro, uma busca, uma reclamação. O formulário tem um container principal e vários campos filhos.

tagfunção
<form>Container principal do formulário.
<input>Campo do formulário; o atributo type define seu comportamento.
<textarea>Campo de texto com múltiplas linhas.
<select> / <option>Campo de seleção; select é o container, option são os itens.
<label>Legenda que descreve o campo relacionado.
<fieldset> / <legend>Agrupa campos em seções e dá um título ao grupo.
<form action="/enviar" method="post"> <fieldset> <legend>Contato</legend> <label for="email">E-mail</label> <input type="email" id="email" required placeholder="voce@email.com"> </fieldset> </form>

O atributo for em <label> vincula a legenda ao campo — clicar nela ativa o campo correspondente.

placeholder

Dica visual dentro do campo vazio.

required

Torna o preenchimento obrigatório.

autofocus

Foca o campo automaticamente ao carregar a página.

pattern

Valida o valor com uma expressão regular.

A HTML5 também trouxe tipos de input mais específicos: tel, date, datetime e number, cada um com comportamento e validação próprios do navegador.

<obsoletas>

Tags que ainda funcionam, mas não deveriam ser usadas

Continuam com suporte em boa parte dos navegadores, mas foram substituídas por alternativas com melhor semântica ou por CSS e podem perder suporte a qualquer momento.

tagsubstituída por
<applet>Incluía applets Java; sem equivalente moderno recomendado.
<center>Propriedade CSS text-align: center.
<dir>Listas <ul>/<ol>.
<font>Propriedades CSS de fonte (font-family, color, etc.).
<image>A tag <img>.
Regra prática: se algo pode ser resolvido com CSS, não é trabalho do HTML a marcação deve descrever conteúdo, não aparência.
